> 适用版本：Cobblemon **1.8.x**（Minecraft **1.21.1**）为主；老整合包常见 **1.6.x / 1.20.1**，部分更老的包是 1.19.2。1.7 → 1.8 改动不小（新增 Alpha、TM、栖息地结构等），跨版本抄攻略时先看版本号。

## Cobblemon 是什么

Cobblemon 是一个开源的《宝可梦》主题 Minecraft 模组，不是独立游戏：

- **只支持 Minecraft Java 版**，基岩版（手机 / 主机 / 微软商店版）**不能玩**，别买错版本。
- 同时提供 **Fabric** 与 **NeoForge** 两种加载器版本；官方明确说 **Fabric 性能更好，推荐 Fabric**。
- 目前可生成、可对战 1–9 世代 **800 只以上**宝可梦；还没有模型的物种会以「替身娃娃」形式出现，这不是你装错了。
- 战斗逻辑基于 **Pokémon Showdown** 引擎，所以属性克制、能力等级、状态、天气这些按正统规则走。
- 除了对战，还有图鉴扫描、骑乘、牧场放养、树果种植与杂交、化石复活、古代结构探索等系统。

本攻略面向中文新手，默认你在玩整合包（单人存档或服务器）。

## 版本对应关系

| Minecraft | 常见 Cobblemon | 说明 |
|---|---|---|
| 1.21.1 | 1.8.x（当前主线） | 官方目前的最新版本线，新整合包基本都在这 |
| 1.20.1 | 1.6.x | 老整合包重灾区，攻略/附属 mod 最多 |
| 1.19.2 | 1.3–1.4 时代 | 现在很少见，别拿新攻略套 |

查版本最快的办法：主菜单 Mods 列表里看 Cobblemon 的版本号，或看整合包页面写的 MC 版本。

## 安装：三条路，选一条

### 路线 A：官方整合包（最省事，推荐新手）

官方提供了两个整合包，都带 Cobblemon 本体和必要前置：

- **Cobblemon [Fabric]**：https://modrinth.com/modpack/cobblemon-fabric
- **Cobblemon [NeoForge]**：https://modrinth.com/modpack/cobblemon-neoforge

安装步骤（以 **Modrinth App** 为例）：

1. 从 https://modrinth.com/app 下载并安装 Modrinth App。
2. 启动后用微软账号登录。
3. 左侧 **Search** 搜 `Cobblemon`，找到官方整合包，点 Install。
4. 回 **Home**，鼠标悬停整合包 → **Play**。

用 **Prism Launcher** 也行：新建实例 → 选 Modrinth 源 → 搜整合包 → 安装。CurseForge 启动器同理。

### 路线 B：手动装 mod（自己配整合包时用）

**Fabric 版**需要两样东西：

| 文件 | 说明 |
|---|---|
| Fabric Loader | 选对应 MC 版本的**推荐版** |
| Fabric API | 必装前置，缺了直接崩 |
| `cobblemon-fabric-x.x.x.jar` | 本体，丢进 `mods/` |

**NeoForge 版**：

| 文件 | 说明 |
|---|---|
| NeoForge | 对应 MC 版本的推荐版 |
| Kotlin for Forge | 必装前置 |
| `cobblemon-neoforge-x.x.x.jar` | 本体 |

安装顺序无所谓，但**前置必须先到位**。启动器推荐用 Prism / Modrinth App，官方启动器手动装 mod 容易搞混版本。

### 路线 C：进别人的服务器

Cobblemon **没有官方服务器**。公共服列表在 https://cobblemon.com/en/servers 和官方 Discord 的 `#server-listings` 频道。进服前确认：

- 服务器用的是 Fabric 还是 NeoForge；
- 客户端要不要额外装服务器专属 mod（很多服要求装他们的整合包）；
- 版本号必须和服务端一致。

## 整合包导入常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动即崩，日志报 `Fabric API` 缺失 | 只放了 Cobblemon | 补 Fabric API |
| 启动即崩，日志报 Kotlin | NeoForge 缺 Kotlin for Forge | 补前置 |
| 进游戏没有宝可梦 | 生成被关 / 生物群系 mod 冲突 | 看服务端 `enableSpawning` 配置，见第 7 篇 |
| 材质全是替身娃娃（紫色玩偶） | 该物种还没有模型 | 正常现象，等更新 |
| 服务器能进但没宝可梦 | 客户端装了服务端没有的生成类 mod | 客户端 mod 与服务端保持一致 |

## 开局第一小时该做什么

先记住一个前提：**你手里没有球，就没有队伍**。所以第一小时的核心是「搞到球 + 搞到图鉴 + 别死」。

### 第 1 步：选初始宝可梦

1.8 版本换了全新的初始选择界面，进世界后会让你挑一只。挑的时候看两点：

- **属性别和后续想抓的重复**（火/水/草各有用途，草系前期打岩石最舒服）；
- **看它能不能学「点到为止」之类的留血招式**（有更好，没有也能玩）。

选完它会跟着你走，右键可以查看状态、切换出战。

### 第 2 步：做图鉴（强烈建议第一件做的事）

有了图鉴才能扫描、记录、查生成信息。配方是 3×3：

| 位置 | 材料 |
|---|---|
| 左上 / 左中 / 左下 | 铁锭 ×3 |
| 中上 / 中下 | 任意颜色的杏果（Apricorn）×2 |
| 右上 / 右下 | 铜锭 ×2 |
| 右中 | 铁锭 ×1 |
| 正中间 | 一种「屏幕」材料（决定图鉴颜色） |

共 **铁锭 4 + 杏果 2 + 铜锭 2 + 屏幕材料 1**。屏幕材料可以是：红石粉、荧石粉、烈焰粉、发光墨囊、海晶碎片、紫水晶碎片、亮粉（Bright Powder）——不同材料对应不同颜色，功能一样。

**用法**：手持图鉴右键长按扫描宝可梦（只记录少量信息），或用球抓到后自动登记完整信息；右键打开图鉴，可看属性、种族值、掉落物、叫声、形态等。

### 第 3 步：砍树 → 石工具 → 找杏果树

杏果树（Apricorn Tree）是世界生成的一部分，树上结 7 种颜色的果子。手采得 1 个果子并留下芽，继续长；用剪刀 + 发射器可以批量收。**第一天尽量采满 7 种颜色各几个**，后面做球全靠它。

### 第 4 步：做第一批精灵球

最基础的 Poké Ball 只要 **4 个同色杏果 + 1 个铜锭**，十字形摆法一次出 **4 个球**。具体配方见第 2 篇《捕捉系统》。

建议第一批做 8–12 个，别一次全用光。

### 第 5 步：第一场战斗

- 靠近野生宝可梦（默认 12 格内）右键即可开战。
- 战斗是回合制，但**你可以自由走动、挖矿、建造**（可在设置里开关自由移动）。
- 打不过就跑：默认走出 32 格自动脱离战斗。
- 打赢给经验，升级会学新招式。

### 第 6 步：天黑前找落脚点

夜晚生成表会切换，刷出来的东西更凶；前期没有装备时，**挖个洞、封门口**比硬刚划算。默认情况下宝可梦倒地（濒死）后约 300 秒自动恢复 20% 血量，别慌。

### 第一小时清单（照着做）

- [ ] 选初始宝可梦
- [ ] 做图鉴（铁 4 + 杏果 2 + 铜 2 + 屏幕 1）
- [ ] 采 7 色杏果各 3–5 个
- [ ] 做 8–12 个基础球
- [ ] 抓 2–3 只不同属性的宝可梦
- [ ] 找到村庄 / 结构，记坐标
- [ ] 天黑前做好安全屋

## 新手最容易犯的错

1. **以为「Catch」按钮会自动投球**：战斗中按 Catch 只是进入投球状态，还是要自己瞄准扔。
2. **拿木棍去打 20 级的宝可梦**：前期看到红眼、体型明显更大的，绕开——那是 Alpha。
3. **把球全扔在一只抓不到的宝可梦上**：捕获失败球会消失，血越少、有异常状态越好抓。
4. **以为能繁殖**：原版 Cobblemon 目前**没有**蛋/繁殖系统（详见第 4 篇）。
5. **跨版本抄配方**：1.7 → 1.8 加了 TM 系统和新结构，老攻略里的某些物品可能已经改名或换配方，游戏内用 JEI / EMI 查最准。
