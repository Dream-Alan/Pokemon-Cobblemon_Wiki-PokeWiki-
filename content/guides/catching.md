> 适用版本：Cobblemon 1.8.x（MC 1.21.1），1.6.x / 1.20.1 配方基本一致。整合包可能改配方，**以游戏内 JEI / EMI 为准**。

## 一、捕捉的三样核心材料

| 材料 | 来源 | 用途 |
|---|---|---|
| **杏果 Apricorn** | 杏果树，7 种颜色 | 球身主材料，决定球的种类 |
| **铜锭 / 铁锭 / 金锭** | 挖矿、熔炼 | 球中间的「基座」，决定球的档位 |
| **Tumblestone（滚石）** | 地下矿脉 | 只用于「古代球」（Ancient 系列） |

### 杏果怎么种、怎么收

- 7 种颜色：**红、黄、绿、蓝、粉、白、黑**。
- 树上分 **4 个生长阶段**，大约 **1 个 Minecraft 天**成熟；骨粉可以催熟。
- 手采只掉 **1 个果子**，树上会留下芽继续长；**种子掉落率约 10%**，想规模化就多采多种。
- **自动化**：红石发射器里装剪刀，对准成熟的杏果树可以批量收割。
- 堆肥（Composter）有 **65%** 概率把杏果提升一级堆肥层。

### Tumblestone 与「古代球」

48 种球里有 **16 种属于 Ancient 系列**，必须用 Tumblestone 而不是金属锭做基座。Tumblestone 在地下成矿脉生成，前期挖矿顺手带一组回来。

## 二、配方总表

所有球都是**十字形 5 格**、一次性产出 **4 个球**：

```
  [上]
[左][中][右]
  [下]
```

- **中间** = 基座（铜锭 / 铁锭 / 金锭 / Tumblestone）
- **上、下、左、右** = 杏果或其他材料

下表中「红黄绿蓝粉白黑」= 对应颜色杏果，「铜/铁/金」= 对应金属锭。顺序为 **上-左-中-右-下**。

### 基础球（1× 捕获率）

| 球种 | 配方（上-左-中-右-下） | 说明 |
|---|---|---|
| Poké Ball | 红-红-**铜**-红-红 | 最通用，成本最低 |
| Citrine Ball | 黄-黄-**铜**-黄-黄 | 黄色系换皮，性能同 Poké |
| Verdant Ball | 绿-绿-**铜**-绿-绿 | 绿色系换皮 |
| Azure Ball | 蓝-蓝-**铜**-蓝-蓝 | 蓝色系换皮 |
| Roseate Ball | 粉-粉-**铜**-粉-粉 | 粉色系换皮 |
| Slate Ball | 黑-黑-**铜**-黑-黑 | 黑色系换皮 |
| Premier Ball | 白-白-**铜**-白-白 | 白色系换皮，纪念球 |

> 这 7 种捕获率都是 **1×**，区别只在颜色。想省钱就只做 Poké Ball。

### 进阶球

| 球种 | 配方（上-左-中-右-下） | 捕获率 | 适用场景 |
|---|---|---|---|
| Great Ball | 蓝-红-**铁**-红-蓝 | **1.5×** | 日常主力，铁比金便宜 |
| Ultra Ball | 黑-黄-**金**-黄-黑 | **2×** | 抓稀有 / 高等级目标 |
| Safari Ball | 黄-绿-**铜**-绿-白 | **1.5×**（战斗外） | 野外遭遇战之外的投掷 |
| Fast Ball | 红-黄-**铁**-黄-白 | **4×**（基础速度 ≥100） | 抓电系、飞行系、高速宝可梦 |

> Ultra Ball 的中间是**金锭**，别拿铁锭试半天。
> Fast Ball 的 4 倍只对**基础速度 ≥100** 的物种生效，抓慢速坦克就是普通球。

### 拿不到 / 做不出来的球

| 球种 | 情况 |
|---|---|
| **Net / Dive / Lure Ball** | 不能合成，只能从 **Shipwreck Cove（沉船湾）** 这类小型地牢的**镶金箱子**里开出来 |
| **Cherish Ball** | 生存模式**无法获得** |
| **Ancient Origin Ball** | 生存模式**无法获得** |
| **Master Ball** | 生存模式不可合成，通常由整合包/服务器发放或调整 |

> 48 种球里 **46 种可合成**，剩下 2 种（Cherish、Ancient Origin）生存拿不到。别在 JEI 里翻半天。

## 三、捕获率怎么算

Cobblemon 沿用了原作的捕获判定思路，影响最终成功率的因素大致是：

| 因素 | 影响 |
|---|---|
| **球种倍率** | 1× / 1.5× / 2× / 4×，见上表 |
| **剩余 HP** | 血越少越好，红血时收益最大 |
| **异常状态** | 睡眠、麻痹提升最大，中毒/灼伤/冰冻次之 |
| **物种基础捕获率** | 种族设定，越稀有越低 |
| **等级** | 等级越高越难 |
| **特殊球条件** | 满足条件时才吃倍率（如 Fast Ball 的速度条件） |

**实用结论**：

1. 想抓某只，先把它打到 **1/3 血以下**；
2. 有**睡眠 / 麻痹**手段就先上状态；
3. 普通目标用 Great Ball 起步，稀有目标直接 Ultra Ball；
4. 别用 4 个球去试一只 40 级的准神——先做够球。

## 四、投球操作

1. 把球放进**快捷栏**，选中它。
2. **手持右键**朝目标投掷，有抛物线和落点判定。
3. 战斗中按 **Catch** 只是进入投球状态，**不会自动帮你扔**，还是要自己瞄准。
4. **没砸中**：球会掉在地上，可以捡回来。
5. **砸中但捕获失败**：球会消失，宝可梦逃跑或继续战斗。
6. **捕获成功**：宝可梦进队伍；队伍满 6 只则自动送进 PC。
7. 捕获成功会自动登记到**图鉴**，比扫描（只记少量信息）完整得多。

小细节：如果你已经在该图鉴里登记过这个物种，成功捕获时会播放**「只晃一下」的会心捕获动画**——这是表现效果，不是判定变了。

## 五、省球与效率建议

| 目标 | 做法 |
|---|---|
| 量产普通球 | 种 7 色杏果 + 挖铜；一个铜锭 4 个球，铜比铁便宜 |
| 抓高速宝可梦 | 专门留 Fast Ball（红黄铁黄白） |
| 抓夜间/洞穴货 | 备 Dusk Ball（绿黑金黑绿） |
| 抓水系 | 备 Net Ball / Dive Ball（只能开箱，省着用） |
| 抓重复物种 | Repeat Ball（黑红金红黄）性价比高 |
| 前期缺金 | Great Ball（铁基座）够用，别硬追 Ultra |

> 配方与倍率来自官方 Wiki 的 Poké Ball / Apricorn 页面；整合包若改了配方或倍率，以 JEI / EMI 和服务器说明为准。本文没有把握的倍率（如 Level / Timer / Repeat 的具体系数）一律未写死。
