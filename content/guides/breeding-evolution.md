> 适用版本：Cobblemon 1.8.x（MC 1.21.1）。这一篇的结论对 1.6.x / 1.20.1 同样成立。

## 一、最重要的结论：原版 Cobblemon 没有繁殖

先把最容易踩的坑说清楚：

| 你可能听说的 | 实际情况 |
|---|---|
| 「喂蛋糕 / 放牧场就会生蛋」 | **原版没有蛋系统**，牧场只是放养和展示，不繁殖 |
| 「两只同蛋组放一起会下蛋」 | Cobblemon 目前**没有蛋组、没有蛋、没有孵化步数** |
| 「百变怪能配种」 | 同上，没有配种机制 |
| 「1.8 加了繁殖」 | 没有。官方把 **breeding 列在「计划中」**的功能里 |

依据：Cobblemon 官方 Modrinth 页面的说明里明确写着，还有很多功能在开发中，**包括 NPC、breeding、mega 进化**等。官方 Wiki 也**没有** Breeding / Egg 词条。

所以：**任何告诉你「喂某样东西就生蛋」「走 N 步孵化」的中文攻略，要么在讲附属 mod，要么是编的。**

### 那想要繁殖怎么办

只能用**附属 mod**，例如社区里常见的 `DaycarePlus`（GitHub: Provismet/DaycarePlus）。这类 mod 会自己加托管所、蛋、孵化逻辑，机制和数值**完全取决于该 mod 的版本**，本文不给数字。

判断你玩的整合包有没有繁殖：

1. 看 `mods` 文件夹里有没有 Daycare 类 mod；
2. 游戏内 JEI / EMI 搜 `egg` 或 `daycare`；
3. 问服务器公告——很多服故意不加繁殖，避免刷个体值。

## 二、没有繁殖，原版怎么「培育」

原版的养成路线是：**野外挑选 → 训练 → 用道具修正**。

| 需求 | 原版手段 | 说明 |
|---|---|---|
| 提高个体值（IV） | **Hyper Training（极限特训）** | 用糖，每颗 **±1 点**个体值 |
| 改性格 | **薄荷（Mint）** | 只改能力加成方向，不改原性格显示 |
| 洗努力值（EV） | **减努力树果** | 6 种树果对应 6 项能力 |
| 提升亲密度 | 携带同行、战斗、走路 | 亲密度上限 **255**（`maxPokemonFriendship`） |
| 提升等级 | 战斗、Exp Candy | 等级上限 **100**（`maxPokemonLevel`） |
| 学招式 | 升级、TM、回忆 | 见第 5 篇 |

### Hyper Training 的糖怎么来

- 共 **12 种糖**：6 项能力 × 加 / 减。
- **+1 糖**配方：对应减努力树果 + **蜂蜜（Honeycomb）** + **Exp Candy L 或 XL**，下锅烹饪。
- **−1 糖**配方：把树果换成 **Enigma Berry**。

减努力树果与能力的对应（记住这张表就够）：

| 树果 | 降低的能力 |
|---|---|
| Pomeg | HP |
| Kelpsy | 攻击 |
| Qualot | 防御 |
| Hondew | 特攻 |
| Grepa | 特防 |
| Tamato | 速度 |

> 具体烹饪容器与配方以 JEI / EMI 为准；不同版本可能有微调。

## 三、进化：什么时候进化由你决定

Cobblemon 的进化是**手动触发**的：条件满足后，在队伍 / 宝可梦详情界面选择进化，而不是等级一到自动变。官方宣传语就是「在你决定的时候进化」。

### 常见进化条件类型

| 类型 | 例子 | 备注 |
|---|---|---|
| **等级** | 大多数两段 / 三段进化 | 到级后手动确认 |
| **进化石** | 皮卡丘 → 雷丘、伊布 → 水/火/雷/叶/冰 | 见下表 |
| **亲密度** | 伊布 → 太阳/月亮伊布（昼夜区分） | 亲密度上限 255 |
| **时间** | 白天 / 夜晚限定 | 与亲密度类常叠加 |
| **地点** | 特定群系 / 结构 | 视物种而定 |
| **招式** | 学会某招式后进化 | 视物种而定 |
| **性别** | 奇鲁莉安（♂）→ 艾路雷朵 | 性别不对不进化 |
| **道具携带 / 使用** | 部分物种 | 以游戏内提示为准 |

**怎么知道某只怎么进化**：打开图鉴 / 宝可梦详情，进化条件会直接写在里面；1.8 的图鉴信息比老版本完整得多。

### 进化石一览（10 种）

| 石头 | 典型进化例 |
|---|---|
| **火之石** | 伊布 → 火伊布；卡蒂狗 → 风速狗 |
| **雷之石** | 皮卡丘 → 雷丘；三合一磁怪 → 自爆磁怪 |
| **水之石** | 海星星 → 宝石海星；伊布 → 水伊布 |
| **叶之石** | 臭臭花 → 霸王花；伊布 → 叶伊布 |
| **月之石** | 皮皮 → 皮可西；向尾喵 → 优雅猫 |
| **日之石** | 向日种子 → 向日花怪 |
| **觉醒石** | 奇鲁莉安（♂）→ 艾路雷朵；雪童子（♀）→ 雪妖女 |
| **暗之石** | 黑暗鸦 → 乌鸦头头；灯火幽灵 → 水晶灯火灵 |
| **光之石** | 波克基古 → 波克基斯；毒蔷薇 → 罗丝雷朵 |
| **冰之石** | 穿山鼠（阿罗拉）→ 穿山王；伊布 → 冰伊布；好胜蟹 → 好胜毛蟹 |

### 进化石怎么获取

| 方式 | 说明 |
|---|---|
| **挖矿** | 生成「进化石矿脉」（Evolution Stone Ore），时运（Fortune）提高产量 |
| **精准采集** | 用 Silk Touch 挖到的是矿石方块，需要**再烧炼**才出石头 |
| **合成存储方块** | 9 个同种石头可合成储存方块，也能反向拆回 |
| **结构 / 战利品** | 部分结构箱子会给，视版本 |

顺带一提：进化石方块会**发光**，不同石头的亮度不一样（日之石 5、雷之石 8、光之石 11、火之石 13、觉醒石 15），可以当装饰灯用。

## 四、培育路线建议（无繁殖版）

| 阶段 | 目标 | 做法 |
|---|---|---|
| 开局 | 凑齐 6 只不同属性 | 见第 2 篇，先抓再看个体值 |
| 中期 | 主力升到 50+ | 打野生、吃 Exp Candy |
| 中期 | 补关键进化 | 挖进化石，优先补队伍缺的属性 |
| 后期 | 修正个体值 | 攒树果 + 蜂蜜 + Exp Candy 做糖 |
| 后期 | 洗努力值 | 减努力树果，重新分配 |
| 毕业 | 满级 + 满亲密度 | 亲密度影响部分进化与部分招式威力 |

### 亲密度怎么涨

- 带着它**走路、战斗、升级**都会涨；
- 别让它频繁濒死（会掉）；
- 某些树果 / 道具能加速（以游戏内提示为准）；
- 上限是 **255**，到顶后不再变化。

## 五、这一篇的坑点清单

1. **别信「繁殖攻略」**——原版没有，附属 mod 才有。
2. **别把进化石直接扔地上**——它是矿石烧出来的，丢了很亏。
3. **Silk Touch 挖的矿石要烧**，不是直接能用。
4. **进化不自动**：等级到了要去界面点，很多人以为卡 bug。
5. **性别 / 时间不对就不进化**：奇鲁莉安要雄性，雪童子要雌性，伊布亲密度进化分昼夜。
6. **亲密度到 255 再谈进化**：没到就是没到，喂东西也没用。
7. **个体值不是越高越好**：有些玩法需要 0 速 / 0 攻，先想清楚再喂糖。

> 进化石种类与进化例来自官方 Evolution Stone 页面；Hyper Training 的糖配方来自官方页面。具体某只宝可梦的进化条件，请以游戏内图鉴显示为准——那是唯一不会骗你的地方。
