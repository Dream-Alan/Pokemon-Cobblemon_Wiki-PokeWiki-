> 适用版本：Cobblemon 1.8.x（MC 1.21.1）。这一篇的结论对 1.6.x / 1.20.1 同样成立。

## 一、最重要的结论：原版 Cobblemon 没有繁殖

先把最容易踩的坑说清楚：

| 你可能听说的 | 实际情况 |
|---|---|
| 「喂蛋糕 / 放牧场就会生蛋」 | **原版没有蛋系统**，牧场只是放养和展示，不繁殖 |
| 「两只同蛋组放一起会下蛋」 | Cobblemon 目前**没有蛋组、没有蛋、没有孵化步数** |
| 「百变怪能配种」 | 同上，没有配种机制 |
| 「1.8 加了繁殖」 | 没有。官方把 **breeding 列在「计划中」**的功能里 |

依据：Cobblemon 官方 Modrinth 页面的说明里明确写着，还有很多功能在开发中，**包括 NPC、breeding、mega 进化**等。官方 Wiki 也**没有** Breeding / Egg 词条。

所以：**任何告诉你「喂某样东西就生蛋」「走 N 步孵化」的中文攻略，要么在讲附属 mod，要么是编的。**

### 那想要繁殖怎么办

只能用**附属 mod**，例如社区里常见的 `DaycarePlus`（GitHub: Provismet/DaycarePlus）。这类 mod 会自己加托管所、蛋、孵化逻辑，机制和数值**完全取决于该 mod 的版本**，本文不给数字。

判断你玩的整合包有没有繁殖：

1. 看 `mods` 文件夹里有没有 Daycare 类 mod；
2. 游戏内 JEI / EMI 搜 `egg` 或 `daycare`；
3. 问服务器公告——很多服故意不加繁殖，避免刷个体值。

## 二、没有繁殖，那 IV 怎么补？两套系统别混

这里最容易混淆：**方可梦用「糖」，正作用「王冠」**，两套东西长得像、逻辑完全不同，混着记就会得出「王冠堆出 6V 再生蛋」这种错误结论。

| 需求 | 方可梦（Cobblemon）手段 | 正作（主系列）手段 |
|---|---|---|
| 提高个体值（IV） | 极限特训糖，每颗 **±1 点** | 银色 / 金色王冠 + NPC 极限特训 |
| 改性格 | 薄荷（Mint） | 薄荷（Mint） |
| 洗努力值（EV） | 减努力树果 | 减努力树果 / 洗努力服务 |
| 提升亲密度 | 携带同行、战斗、走路 | 携带同行、战斗、走路、结伴道具 |
| 提升等级 | 战斗、Exp Candy | 战斗、神奇糖果 |
| 学招式 | 升级、TM、回忆 | 升级、TM、教学、回忆 |

### 2.1 方可梦：极限特训糖（直接改个体值）

Cobblemon 从 **1.7** 起加入了官方的 Hyper Training 道具，也就是「糖」：**12 种，6 项能力 × 加 / 减**，每颗直接把对应个体值 **±1**。

- **+1 糖**配方：对应减努力树果 + **蜂蜜（Honeycomb）** + **Exp Candy L 或 XL**，下锅烹饪。
- **−1 糖**配方：把树果换成 **Enigma Berry**（用来做 0 攻 / 0 速这类特调）。

减努力树果与能力的对应（记住这张表就够）：

| 树果 | 降低的能力 |
|---|---|
| Pomeg | HP |
| Kelpsy | 攻击 |
| Qualot | 防御 |
| Hondew | 特攻 |
| Grepa | 特防 |
| Tamato | 速度 |

> 具体烹饪容器与配方以 JEI / EMI 为准；不同版本可能有微调。方可梦没有繁殖，所以「改了 IV 会不会遗传」在这里不成立。

**别把「瓶盖」当成方可梦本体道具**：Cobblemon 本体没有 Bottle Cap，那是附属 mod（如 WantedItems、Only Bottle Caps 之类）加的，而且其中不少会**直接改真实 IV**而不是「按 V 计算」，和正作的王冠不是一回事。装了什么 mod，就按那个 mod 的说明用。

### 2.2 正作：银色 / 金色王冠 + NPC 极限特训

正作里补 IV 的正规做法是 **极限特训（Hyper Training）**：拿王冠去找固定 NPC，把某项（或全部）能力的**计算值**按 31 算。

| 王冠 | 效果 | 前提 |
|---|---|---|
| **银色王冠** | 把**一项**能力提升到满个体（31）时的数值 | 宝可梦达到要求等级（见下） |
| **金色王冠** | 把**六项**全部提升到满个体时的数值 | 同上 |

**等级门槛与 NPC 位置随版本变化**：

| 作品 | 等级要求 | 找谁 |
|---|---|---|
| 太阳 / 月亮 | 100 级（且已登入名人堂） | 好奥乐市购物中心的「极限大叔」 |
| 剑 / 盾 | 100 级 | 宫门市对战塔柜台的职员 |
| 朱 / 紫 | **50 级** | 冰柜镇宝可梦中心北侧、身边带暴雪王的 NPC |

王冠常见的获取途径（不同版本有差异）：剑盾的极巨团体战（4–5 星掉率高）、旷野地带挖宝兄弟（500 瓦特一次）、对战塔大师球级奖励；朱紫的信使鸟包包（集齐 6 枚徽章后 **20000 一个银色王冠**）、5 星以上太晶团体战、渍沁镇拍卖、级别对战奖励，金色王冠更稀有，通常靠拍卖或 6 星太晶战。

### 2.3 关键结论：王冠**不改变**原始个体值

这是全篇最该记住的一条：

- 极限特训只是让**能力值的计算**按满个体处理，宝可梦的**真实 IV 一点没变**；
- 所以 **生蛋遗传的还是原始 IV**——王冠堆出来的 6V 传不下去；
- 觉醒力量的属性判定同样不变；
- 状态界面里那一项会显示「极限特训」标记，而不是「最棒（Best）」。

换句话说：**想靠王冠「养出」6V 再拿去生蛋，是行不通的**；反过来说，先天的 6V 蛋种也没法靠王冠替代。同理，**薄荷只改能力加成方向，不改正作的原始性格**，孵蛋遗传的仍是原来的性格。

## 三、进化：什么时候进化由你决定

Cobblemon 的进化是**手动触发**的：条件满足后，在队伍 / 宝可梦详情界面选择进化，而不是等级一到自动变。官方宣传语就是「在你决定的时候进化」。

### 常见进化条件类型

| 类型 | 例子 | 备注 |
|---|---|---|
| **等级** | 大多数两段 / 三段进化 | 到级后手动确认 |
| **进化石** | 皮卡丘 → 雷丘、伊布 → 水/火/雷/叶/冰 | 见下表 |
| **亲密度** | 伊布 → 太阳/月亮伊布（昼夜区分） | 亲密度上限 255 |
| **时间** | 白天 / 夜晚限定 | 与亲密度类常叠加 |
| **地点** | 特定群系 / 结构 | 视物种而定 |
| **招式** | 学会某招式后进化 | 视物种而定 |
| **性别** | 奇鲁莉安（♂）→ 艾路雷朵 | 性别不对不进化 |
| **道具携带 / 使用** | 部分物种 | 以游戏内提示为准 |

**怎么知道某只怎么进化**：打开图鉴 / 宝可梦详情，进化条件会直接写在里面；1.8 的图鉴信息比老版本完整得多。

### 进化石一览（10 种）

| 石头 | 典型进化例 |
|---|---|
| **火之石** | 伊布 → 火伊布；卡蒂狗 → 风速狗 |
| **雷之石** | 皮卡丘 → 雷丘；三合一磁怪 → 自爆磁怪 |
| **水之石** | 海星星 → 宝石海星；伊布 → 水伊布 |
| **叶之石** | 臭臭花 → 霸王花；伊布 → 叶伊布 |
| **月之石** | 皮皮 → 皮可西；向尾喵 → 优雅猫 |
| **日之石** | 向日种子 → 向日花怪 |
| **觉醒石** | 奇鲁莉安（♂）→ 艾路雷朵；雪童子（♀）→ 雪妖女 |
| **暗之石** | 黑暗鸦 → 乌鸦头头；灯火幽灵 → 水晶灯火灵 |
| **光之石** | 波克基古 → 波克基斯；毒蔷薇 → 罗丝雷朵 |
| **冰之石** | 穿山鼠（阿罗拉）→ 穿山王；伊布 → 冰伊布；好胜蟹 → 好胜毛蟹 |

### 进化石怎么获取

| 方式 | 说明 |
|---|---|
| **挖矿** | 生成「进化石矿脉」（Evolution Stone Ore），时运（Fortune）提高产量 |
| **精准采集** | 用 Silk Touch 挖到的是矿石方块，需要**再烧炼**才出石头 |
| **合成存储方块** | 9 个同种石头可合成储存方块，也能反向拆回 |
| **结构 / 战利品** | 部分结构箱子会给，视版本 |

顺带一提：进化石方块会**发光**，不同石头的亮度不一样（日之石 5、雷之石 8、光之石 11、火之石 13、觉醒石 15），可以当装饰灯用。

## 四、培育路线建议（方可梦，无繁殖版）

| 阶段 | 目标 | 做法 |
|---|---|---|
| 开局 | 凑齐 6 只不同属性 | 见第 2 篇，先抓再看个体值 |
| 中期 | 主力升到 50+ | 打野生、吃 Exp Candy |
| 中期 | 补关键进化 | 挖进化石，优先补队伍缺的属性 |
| 后期 | 修正个体值 | 攒树果 + 蜂蜜 + Exp Candy 做糖（每颗 ±1，见 2.1） |
| 后期 | 洗努力值 | 减努力树果，重新分配 |
| 毕业 | 满级 + 满亲密度 | 亲密度影响部分进化与部分招式威力 |

> 玩正作的话思路反过来：**先挑先天个体值好的（或直接极限特训）**，王冠只解决「能打」，解决不了「能遗传」——想孵 6V 还是得靠蛋种。

### 亲密度怎么涨

- 带着它**走路、战斗、升级**都会涨；
- 别让它频繁濒死（会掉）；
- 某些树果 / 道具能加速（以游戏内提示为准）；
- 上限是 **255**，到顶后不再变化。

## 五、这一篇的坑点清单

1. **别信「繁殖攻略」**——原版没有，附属 mod 才有。
2. **别把进化石直接扔地上**——它是矿石烧出来的，丢了很亏。
3. **Silk Touch 挖的矿石要烧**，不是直接能用。
4. **进化不自动**：等级到了要去界面点，很多人以为卡 bug。
5. **性别 / 时间不对就不进化**：奇鲁莉安要雄性，雪童子要雌性，伊布亲密度进化分昼夜。
6. **亲密度到 255 再谈进化**：没到就是没到，喂东西也没用。
7. **个体值不是越高越好**：有些玩法需要 0 速 / 0 攻，先想清楚再喂糖（反正糖也能 −1）。
8. **王冠 ≠ 改个体值**：正作的极限特训只让能力值按 V 计算，真实个体值不变 → **孵蛋不继承**、觉醒力量也不变。
9. **薄荷不改原始性格**：孵蛋遗传的仍是原来的性格，别指望用薄荷「调」蛋种。

> 进化石种类与进化例来自官方 Evolution Stone 页面；Cobblemon 的糖配方来自官方 Hyper Training 页面；王冠的等级门槛、NPC 位置与「不改变真实个体值」来自 Bulbapedia / Game8 的极限特训词条。具体某只宝可梦的进化条件，请以游戏内图鉴显示为准——那是唯一不会骗你的地方。
