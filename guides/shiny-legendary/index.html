闪光与传说：概率、Alpha 与那些刷不到的东西

1/8192 的闪光、Alpha 机制，以及传说到底怎么来

闪光传说Alpha稀有

适用版本：Cobblemon 1.8.x（MC 1.21.1）。1.8 才引入 Alpha，1.6.x 没有。

一、闪光（Shiny）是什么

闪光就是颜色不同的同种宝可梦，纯外观差异：

  • 不影响属性、个体值、努力值、招式；
  • 图鉴里会单独记录；
  • 抓到后可以正常使用、进化、对战。

在 Cobblemon 里，闪光宝可梦在远处就会提示你：配置项 shinyNoticeParticlesDistance 默认 24 格，范围内会播放音效 + 字幕提醒。所以听到「叮」的一声别只顾着跑。

二、闪光概率：1/8192

官方 Config 页面写得很清楚：

配置项默认值含义
shinyRate8192.0生成时是闪光的概率，按 1/x 计算
shinyRate = 0—关闭闪光生成

也就是默认 1/8192（约 0.012%）。

但是：

  • 服务器/整合包作者几乎都会改这个值，很多包会调到 1/1024 甚至更低；
  • 所以「你的服闪光多久一只」只能看服务端配置，别人的数字对你无效；
  • 单人游戏可以在 config/cobblemon/main.json 里看 shinyRate（改完要重启）。

怎么确认自己服的闪光率

方法说明
看服务端 config/cobblemon/main.json最直接，找 shinyRate
问管理员很多服会在公告里写
装附属 mod 看提示部分 UI 类 mod 会显示概率

三、提高闪光「效率」的正确思路

闪光概率本身在生成时判定，玩家能改的只有生成次数。所以：

做法效果说明
提高生成频率✅ 有效在合适群系连续移动，刷更多个体
抓/打掉杂鱼✅ 有效减少 8 格最小间距的占用
钓鱼✅ 有效每次抛竿都是一次生成判定
打 Alpha❌ 无关Alpha 和闪光是两个独立判定，别混淆
连锁 / 连击⚠️ 未查证原版没有官方「连锁提升闪光」机制，别信
闪光护符⚠️ 未查证是否有该道具取决于版本/整合包，JEI 搜 shiny 确认

最实在的一条：想刷闪光，就找一个生成量大、你打得过的群系，一边走一边抓。效率 = 每秒生成数 × 你的清场速度。

关于「改概率」的 mod / 插件

Cobblemon 提供了 ShinyChanceCalculationEvent 事件，附属 mod 可以用 addModifier(...) 或 addModificationFunction(...) 改闪光概率。所以如果你装了这类 mod，实际概率可能已经不是 8192 了——以该 mod 的配置为准。

四、Alpha：1.8 的「准 Boss」

Alpha 是 1.8.0「Make Your Move」加入的强化野生宝可梦，也是目前原版最接近「Boss」的东西。

外观与行为

  • 体型明显更大，红眼；
  • 身边带一群最低进化形态的小弟（herd）；
  • 自然生成的 Alpha 一定是最终进化形态；
  • 主世界稀有随机生成，不挑群系（具体权重看生成表）。

等级规则

Alpha 的等级会跟着你队伍里最高等级上浮：

你队伍最高等级Alpha 加成
< 21+4
21–30+8
31–45+12
46–65+16
> 65+20

上限 100（受 maxPokemonLevel 限制）。

战斗加成与掉落

项目内容
开战加成随机获得 1 + 每 10 级 1 个能力提升
招式必带 2 个 TM 招式
掉落Exp Candy、IV 糖果、Type Gem、对应属性树果
可捕获可以抓，抓到就是成品 Alpha

固定概率的 Alpha 来源

来源概率
钓鱼 / Poké Snack1/100
化石复活1/20
化石 + Hopo Berry 当调味料再 +2%

也就是说：想稳定拿 Alpha，钓鱼比野外瞎逛靠谱得多。

五、传说宝可梦：先把话说清楚

这是中文社区谣言最多的地方。事实是：

  1. Cobblemon 的数据里确实有传说宝可梦（超梦、梦幻、急冻鸟、闪电鸟、火焰鸟等都在物种文件里），可以生成、可以对战、可以被命令调出。
  2. 但官方 Wiki 没有「传说自然生成」的说明页，也没有公开的传说专属生成条件文档。
  3. 原版能不能在野外遇到传说，取决于你所用版本的生成表（官方按版本发布，整合包还可能改）。
  4. 绝大多数整合包/服务器是用附属 mod 或活动来放传说，而不是靠原版生成。

所以传说一般这么来

途径说明
附属 mod如 Legendary Spawns、Legends Untold、Cobblemon Legendaries 等，机制各不相同
服务器活动管理员手动刷、限时活动、抽奖
管理员命令用生成/给予类命令直接发（具体命令看 /help）
整合包自定义数据包里写死生成条件，只有作者知道

别做的事：不要按「某群系挖到 Y=-40 就会出超梦」这类攻略去蹲点——没有任何官方依据。

怎么确认你的包有没有传说生成

  1. 看 mods 里有没有 Legendary 类 mod；
  2. 看整合包说明/服务器公告；
  3. 游戏内问管理员；
  4. 看数据包 spawn_pool_world 里有没有对应物种的 JSON。

六、Boss / 图腾 / 结构

Cobblemon 原版没有「Boss 图腾」这套系统。玩家口中的「Boss」通常指：

说法实际指
BossAlpha（红眼大体型）
图腾部分整合包/附属 mod 的机制，原版没有
地牢 Boss结构里的强力野生宝可梦，不是独立 Boss 系统

1.8 新增了 49 种栖息地结构（Habitat） 和更多古代结构。结构里的镶金箱子能开出稀有球（Net / Dive / Lure）和其他战利品，值得专门跑一趟。

探索结构的小建议：

  • 带够球再进地牢（里面刷的都是稀有货）；
  • 镶金箱子优先开；
  • 记坐标，很多结构会重复利用。

七、稀有度速查表

目标难度关键点

八、心态建议

  1. 闪光不要「蹲」：站在原地概率是 0，因为生成只在 16–64 格内发生。
  2. Alpha 不要越级打：它是按你队伍等级上浮的，但你队伍的「平均实力」不会跟着涨。
  3. 传说不要信攻略：先确认你的包到底有没有传说生成。
  4. 抓到就记录：图鉴登记后，以后再遇到同种会更容易辨认（会心捕获动画）。

闪光默认概率 1/8192 来自官方 Config 页面，shinyRate 可被服务端修改；Alpha 的等级与掉落来自官方 Alpha 页面。传说部分本文只写确定的事实，未查证的「生成条件」一律不给数字。
